# PlanWise — план «Фокус дня» на существующем интерфейсе (20.10.2026)

Продолжает `2026-10-18-planwise-essence.md` (суть: цикл «записал → выбрал реальное → сделал → закрыл») и
`2026-10-19-planwise-audit.md`. Метод: прогон 0.3.4 в браузере (телефон 412 px и десктоп 1280 px) на
реалистичном дне — 8 задач на сегодня, 2 хвоста (↻2 и ↻0), 2 повтора, 3 задачи «Позже».
Прототип итогового вида: `docs/prototypes/focus-day.html` (v3 — повторяет текущие экраны, меняет только то,
что ниже; переключатель «новые карточки» показывает строки до/после).

**Вердикт:** экраны переделывать не нужно. Каркас (верхняя панель, День/Неделя/Месяц, карточки, «Позже»,
«Закрыть день») остаётся. Не хватает трёх вещей внутри экрана «День»: **что главное**, **сколько реально
влезет**, **мягкий выход из застрявших задач**. Плюс облегчить «Закрыть день» и захват на телефоне.

## 1. Что увидел на прогоне — проблемы

| # | Проблема | Что видно | Психология | Вред |
|---|---|---|---|---|
| P1 | Все задачи дня равны | 8 строк одного веса, порядок — время, потом ручной | Каждый взгляд = заново решать «с чего начать» (усталость от решений) → откладывание | высокий |
| P2 | Перегруз не виден | 8 задач при обычных 5 — нигде не сказано | Ошибка планирования: день заканчивается «провалом» по построению | высокий |
| P3 | «Закрыть день» тяжёлый | 8 задач × 3 кнопки = 24 решения; «Отпустить» **красная**; нет «всё на завтра» | Ритуал дороже пользы → его бросают; красный = вина за честное решение | высокий |
| P4 | ↻3 — тупик | «Завтра» просто серая; что делать — не сказано | Блок без выхода = раздражение; задача так и висит | средний |
| P5 | Статус разбросан | «Сегодня сделано: 2», строка хвостов, «Обычно…» — три строки текста над списком | Шум над главным; хвосты в отдельной строке читаются как упрёк | средний |
| P6 | Захват на телефоне | «+ добавить задачу» в конце списка, уезжает вниз | Мысль не записана за 3 секунды = потеряна (голова не свободна) | средний |
| P7 | Шум | «Архив (0)» на телефоне; сделанное перемешано с открытым; пустая зона «завтра» на десктопе | Визуальный мусор, сделанное не отделено → нет ощущения движения | низкий |
| P8 | Два цветовых кода | в карточке задачи — приоритет (3 цветных точки) и цвет-категория | Цвет перестаёт что-то значить; приоритет нигде не используется | низкий |
| P9 | Неделя без итога | у месяца есть сводка, у недели — нет | Прогресс за неделю не виден (принцип прогресса, Amabile) | низкий |
| P10 | Строка задачи перегружена | на телефоне 4–5 элементов в строке: ручка, галочка 18 px, название, серые «таблетки», ✎; ручка и ✎ там не нужны (тап и так открывает карточку); подзадачи раскрыты под каждой строкой; полоса категории — второй цветовой код | Глаз не находит главное (время, ↻) среди равных серых меток; мелкая галочка — промахи, а отметка «сделано» — главный момент награды | средний |
| P11 | Карточка «всё сразу» | ~25 целей нажатия открыты одновременно (приоритет, 4 больших кнопки повтора, уведомление, цвет, файлы с поясняющим текстом); перенос — через отдельное окно; красная «Удалить» на одном уровне с «Сохранить» | Каждое открытие = просмотр всех полей (нагрузка Хика); лёгкое случайное удаление; простое «на завтра» требует трёх шагов | средний |

## 2. Оценка существующих функций — что дают и насколько нужны

Ценность: 5 — ядро, без неё приложения нет; 3 — заметно помогает; 1 — почти не нужна. Решение — что
делаем в итоговом виде.

| Функция | Что даёт человеку | Ценность | Решение |
|---|---|---|---|
| Неделя (сетка/список) | Планировать вперёд, переносить перетаскиванием | 5 | Оставить как есть + ★ на карточках + сводка недели |
| День | Сейчас — дубль колонки недели | 3 → 5 | **Становится центром фокуса**: главное, черта, статус |
| Месяц + сводка | Обзор, дальние даты, итог месяца | 3 | Оставить |
| «Позже» (правая панель) | Мысль без даты не теряется | 4 | Оставить (уже свёрнут) |
| Закрыть день | Голова свободна вечером (Masicampo) | 5 | Облегчить (P3) |
| Статус «Отпущено» | Отказ без вины, честная история | 4 | Оставить, кнопку сделать нейтральной |
| Счётчик переносов ↻ | Ловит «зомби»-задачи | 4 | Оставить, на ↻3 — выход вместо блока |
| «Обычно закрываете N» | Реальная ёмкость дня из истории | 3 → 4 | Превратить в черту в списке (P2) |
| Повторы ⟳ | Привычки и регулярные дела без ручного ввода | 4 | Оставить |
| Быстрый ввод с разбором даты | «завтра созвон в 15» за 3 секунды | 4 | Вынести в липкую строку на телефоне (P6) |
| Время, длительность | Расписание дня, конфликты | 4 | Оставить; длительность есть только у задач со временем — для загрузки не годится |
| Приоритет (низкий/средний/высокий) | Цветная точка, больше ни на что не влияет | 2 | **Заменить на ★ «Главное»** (P8) |
| Цвет-категория | Работа/Личное/Спорт видно сразу | 3 | Оставить единственным цветом |
| Напоминания, «пора выезжать» | Не пропустить по времени | 4 | Оставить |
| Утренний дайджест | Утром видно день, не открывая | 3 | Оставить; тап открывает «День» |
| Заметка задачи, файлы, подзадачи | Детали под рукой | 3 / 2 / 3 | Оставить в карточке |
| Заметка дня | Строка «как прошёл день» | 2 | Оставить в «Закрыть день» |
| Поиск | Найти старое | 3 | Оставить |
| Виджеты Android (6 шт.) | День без открытия приложения | 4 | Оставить; ★ в виджете — позже |
| Синхронизация через папку, экспорт | Данные не потеряются | 4 | Оставить |
| Мини-календарь | Дублирует стрелки и «Месяц» | 2 | Оставить (уже скрываемый) |
| Архив | После отмены авто-архива почти пуст | 1 | Прятать, когда пуст |
| 8 переключателей видимости | Настраивать вид | 2 | Не трогать сейчас, не добавлять новых, кроме одного «Главное дня» |
| Зона «следующая неделя» сбоку | Перенос перетаскиванием | 2 | Оставить |

## 4. Итог — как будет выглядеть и почему

**«День» (телефон)** — тот же экран, сверху вниз:

```
‹ 20 Октября ›  📅 ⚙
[День|Неделя|Месяц] 🔍
Вторник, 20 Октября ●             [✓ Закрыть день]
сделано 2 · хвосты 2 · 8 из обычных 5          ← одна строка вместо трёх
┌ Главное · 1/3 ─────────────────────────┐
│ ★ Отчёт по проекту        ↻2           │    ← до 3, выбираются ★ на карточке
│ ★ Созвон с командой       10:00        │
└────────────────────────────────────────┘
  Тренировка                19:00 ⟳
  Купить подарок маме
  Разобрать почту           ↻1
── обычно вы успеваете до сюда ──              ← черта из истории, не запрет
  Записаться к врачу
  Подготовить презентацию
▸ Сделано 2                                    ← свёрнуто
[ + Добавить: «завтра созвон в 15» ]           ← прилипает к низу
```

- Пока главного нет — на месте блока подсказка «Что главное сегодня?» и 2–3 предложения в один тап
  (хвосты, задачи со временем, ↻). Можно закрыть «не сейчас» — ничего не требуется.
- Главное сделано → «Главное сделано. Остальное — по желанию». День уже удался, даже если список не пуст.
- Черта появляется, только когда есть история (14+ дней) и задач больше обычного. Ниже черты задачи
  не исчезают и не краснеют — просто видно, что это бонус.

**«Неделя»** — без изменений по структуре: ★ на карточках, сверху строка «сделано 7 · отпущено 1 ·
застряло 1», липкая строка добавления на телефоне.

**«Закрыть день»:** сделано → главное 2/3 → «Не сделано (5) [Всё на завтра]» → по задаче Завтра / Позже /
Отпустить (нейтральные) → заметка дня → «Закрыть». После — короткий итог. Задачи на ↻3 «Всё на завтра»
пропускает, по ним — окно первого шага.

**↻3:** «Уже 3-й перенос. Обычно это значит, что задача большая или не нужна» → поле «первый шаг на 5–15
минут» + «Сделать первым шагом» / «В Позже» / «Отпустить».

**Строка задачи (P10):**

```
 ◯  Тренировка                         ☆      ← ◯ цвета категории; ☆ на десктопе — при наведении
    19:00–20:00 · ⟳                            ← время акцентом, остальное — приглушённо
 ◯  Отчёт по проекту                   ★
    ↻2 · с вс                                  ← ↻ тревожным цветом с 2-го переноса
 ◯  Подготовить презентацию            ☆
    шаги 1/3                                   ← тап — шаги раскрываются под строкой
```

Тап по строке — карточка; долгое нажатие — перетаскивание (на десктопе ручка при наведении).

**Карточка задачи (P11, P8)** — на телефоне лист снизу:

```
 ◯  Отчёт по проекту                   ★      ← большая галочка, название, «Главное»
    Хвост с вс · переносили 2 раза
 [Сегодня] [Завтра] [Позже] [📅 Дата]          ← перенос в один тап
 🕐 10:00  15м [30м] 1ч 2ч                 ✕   ← строка есть, только если время задано
 ⟳ каждый [день|неделю|месяц]              ✕
 ● [Работа] Личное Спорт без
 ШАГИ 1/3  ☑ Собрать цифры  ☐ …  + шаг
 Заметка…
 + время  + повтор  + напоминание  + файл      ← чего нет — одним чипом
 ⋯                          [Отмена] [Готово]  ← ⋯ = Дублировать / Удалить
```

Ряд «Приоритет» заменяется ★ (P8). «Отмена» и Esc возвращают всё как было; «Готово» и тап мимо листа —
сохраняют. «Завтра» на задаче с ↻2 открывает окно первого шага (P4).

**Настройки:** один новый переключатель «Главное дня» (вкл). Выключен — «День» выглядит как сейчас,
только строка статуса и черта.

Почему так: каждое изменение ложится на то, что уже есть (`difficulty`, `UsualLoad`, `postponeCount`,
`CloseDayDialog`, `quickAdd`), без миграции БД и без нового экрана. Человек делает ровно одно новое
действие — ставит ★; всё остальное приложение считает само.

2. **Черта читается как осуждение** → мягкий текст «обычно успеваете до сюда», появляется только при
   истории, без цвета тревоги.
3. **Старые приоритеты «низкий/средний» исчезнут из вида** → данные в БД не трогаем (поле остаётся),
   «высокий» становится ★; если окажется нужно — вернуть ряд одной правкой.
4. **Без ручки на телефоне перетаскивание не найдут** → один раз подсказка «Удерживайте задачу, чтобы
   перетащить»; задержка долгого нажатия ~300 мс, чтобы не мешать прокрутке.
5. **Скрытые поля карточки «потеряются»** → заданное всегда видно строкой; незаданное — подписанным чипом
   «+ время», а не иконкой без текста.
