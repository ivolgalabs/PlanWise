# Меньше линий, единый радиус, панель не трогает поиск — дизайн

**Дата:** 2026-08-03 · **Итерация 5 UI** · **Статус:** согласован

## 1. Цель

Три связанных улучшения вида интерфейса:
1. **Поиск не трогает правую панель (архитектурно):** панель поднимается на уровень App и становится одним и тем же элементом рядом с областью контента — при открытии/закрытии поиска её ширина, видимость и положение не меняются (сейчас при активном поиске панель рендерится заново: в неделе ширина прыгает 300→280, скрытая панель возвращается, контент с панелью сдвигается вниз строкой поиска).
2. **Меньше линий и рамок:** убрать массовый «забор» (ячейки месяца, линии под задачами, рамки колонок недели, лишние линии правой панели, рамки чипов поиска, зоны сдвига), сохранив навигационные и смысловые линии.
3. **Единый радиус скругления** `radius-md` (как у одобренного поля поиска) во всех карточках/ячейках/панелях/меню.

## 2. Панель на уровне App

**Раскладка App:**
```
<TopBar …/>
<TaskDndContext onChange={reload}>          ← один общий контекст (drag панель⇄дни)
  <div flex row>
    <div flex column flex:1>                 ← левая колонка
      {searchOpen && <SearchBar …/>}         ← строка поиска живёт НАД контентом левой колонки
      <div flex:1>
        {searchActive ? <SearchResults …/> : <виды/>}
      </div>
    </div>
    {panelVisible && <AppRightPanel …/>}     ← правая панель, не размонтируется при поиске
  </div>
</TaskDndContext>
```

- **AppRightPanel** (в App.tsx): в «Неделе» — RightPanel с resize-handle и шириной из localStorage (перенос логики RightCalendar из WeekView); в «Дне» — RightPanel width 280; в «Месяце» — нет панели.
- **panelVisible** = `view !== "month" && showPanel && !calNarrow && (visibility.miniCalendar || visibility.someday)`, где `showPanel` — состояние App (default true), `calNarrow` — media-запрос App с порогом по виду (неделя 1200, день 700).
- Виды **теряют свои TaskDndContext-обёртки** (WeekView, DayView, MonthView) — контекст один на App.
- WeekView: убрать showCalendar/calWidth/calNarrow/RightCalendar и рендер панели; тулбар получает пропсы `showPanel`, `onTogglePanel` (кнопка «Скрыть панель» остаётся). DayView: убрать showPanel/calNarrow и рендер панели; кнопка в заголовке дня — те же пропсы.
- При поиске панель остаётся ровно там, где была: та же ширина (week — calWidth, day — 280), та же видимость (showPanel), не сдвигается по вертикали (строка поиска — над левой колонкой).

## 3. Сокращение линий

1. **Ячейки месяца:** убрать рамку у всех ячеек (было 1px у 42 ячеек); «сегодня» — акцентная рамка-обводка (`boxShadow inset 0 0 0 1.5px accent`, уже есть), выбранный день — акцент-фон (уже есть). Разделение — воздухом (gap) и фоном card.
2. **Линия под задачей:** убрать `border-bottom` у `.task-block` (App.css) — строки разделяются воздухом и hover-фоном.
3. **Колонки недели (сетка):** рамка только у «сегодня» (2px акцент); остальные колонки — фон card + радиус без рамки; выбранный день — акцент-фон.
4. **Список недели (вертикальный):** убрать рамку выбранного дня (остаётся акцент-фон).
5. **Правая панель:** убрать `borderTop` у «+ когда-нибудь» и у полоски «Архив»; остаётся одна линия — разделитель «календарь / Когда-нибудь» (+ borderLeft панели).
6. **Чипы поиска и фильтров:** рамка только у активного/открытого чипа (accent); остальные — текст + hover-фон.
7. **Зона сдвига недели:** убрать dashed-рамку, оставить текст и акцент-фон при наведении/переносе.

**Сохраняется намеренно:** рамка/подсветка «сегодня» в календаре и месяце; акцентная полоска подзадач/заметок (2px слева); рамка поля поиска; линия под полями «+ добавить» (паттерн inline-input).

## 4. Единый радиус

- Заменить `var(--radius-lg)` и `var(--radius-xl)` на `var(--radius-md)` во всех видимых контейнерах: MiniCalendar (карточка), DayColumn (App.css + inline), MonthCell-модалка («Перейти к дню»), color-menu (App.css), SettingsPanel (модалки/секции), DatePickerModal (через MiniCalendar), drag-призрак (px 6 → radius-md).
- Мелкие элементы (свотчи, точки, radius-sm/xs) не трогать.
