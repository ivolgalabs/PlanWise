# Дизайн-спека: Universal UI — финальная система тем

**Дата:** 2026-07-16
**Статус:** Утверждается
**Цель:** Переосмыслить палитры Universal UI для набора рабочих приложений
(Ежедневник, CBZ_view, TensorMedia и др.), обеспечив единый визуальный стиль.

---

## 1. Принципы

Темы для набора инструментов должны удовлетворять трём уровням:

1. **Функциональный** — читаемость (WCAG AA/AAA). Все палитры = AAA по
   основному тексту — тут проблем нет.
2. **Когнитивный** — неутомимость при долгом использовании. Планнер открыт
   часами → важна спокойность, не выразительность.
3. **Идентичность** — тема = характер. Должен быть выбор от
   «профессионально-нейтрального» (slate) до «личного-тёплого» (sepia).

## 2. Решение по палитрам

### Удалены (контрпродуктивны для рабочего набора)

| Палитра | Причина |
|---|---|
| **Crimson** | Красный фон/акцент = психологический стресс. Для планнера с списком дел создаёт тревожность. |
| **Cyberpunk** | Неоновый акцент — декоративный, убивает фокус при чтении текста. |

Итог: 8 палитр × 3 режима (light/dark/oled) = **24 темы**.

### Структура: 6 ролей

**TIER 1 — Рекомендуемые (дефолтные, видны первыми):**

| Роль | Палитра | Контраст accent | Профиль |
|---|---|---|---|
| Дефолт / «Офис» | **Slate** | 6.78 | Нейтральный рабочий конь |
| «Бумага» (tweek-style) | **Sepia** | 5.62 | Тёплый, ближе всего к tweek.so |
| «Антиусталость» | **Evergreen** | 6.39 | Зелёный снижает усталость глаз |
| «Холодный фокус» | **Nord** | 4.03 | Скандинавская классика |

**TIER 2 — Опциональные (доступны, но не на виду):**

| Роль | Палитра | Контраст accent | Заметка |
|---|---|---|---|
| «Ночная продуктивность» | **Midnight** | 5.30 (после усиления) | Tokyo-night, акцент усилен |
| «Классический тёмный» | **Dracula** | 5.18 (после усиления) | Легендарная Dracula, акцент усилен |

**TIER 3 — Скрытые (только по полному списку):**

| Палитра | Контраст | Заметка |
|---|---|---|
| **Amber** | 4.17 | Тёплый, но янтарь утомляет при долгом чтении |
| **Sakura** | 3.15 | Розовый — чисто вкусовщина |

## 3. Усиление акцентов в midnight и dracula

Текущие акценты слишком слабы (контраст 2.5 на белом) — цветные маркеры задач
почти не видны. WCAG-расчёт дал точные замены:

| Палитра | Было (контраст) | Стало (контраст) | HEX |
|---|---|---|---|
| Midnight | `#7aa2f7` (2.52) | `#3060e8` (**5.30**) | насыщеннее синий |
| Dracula | `#bd93f9` (2.41) | `#9444d6` (**5.18**) | насыщеннее фиолет |

Характер палитр сохранён (оттенок тот же, больше насыщенности).

## 4. Дефолт

- **Slate (light)** — дефолт для новых приложений и для Ежедневника.
- Текущий `:root` в themes.css (тёмный slate) меняется на light-slate как
  стартовый, т.к. планнер — дневной инструмент.

## 5. Маркеры задач (color sets)

Цветные маркеры категорий задач (Работа/Личное/Спорт) должны быть видны на
любой теме. Решение: отвязать их от `--accent` и использовать фиксированные
насыщенные цвета, адаптируя только под light/dark режим:
- Light: насыщенные (#C9A87C / #7EB8C4 / #E8A87C)
- Dark/OLED: те же, чуть светлее для контраста с тёмным фоном.
