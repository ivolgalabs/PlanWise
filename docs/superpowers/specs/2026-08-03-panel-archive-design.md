# Панель «Календарь + Когда-нибудь» под календарём, переносы, заметки Enter, произвольный период, архив — дизайн

**Дата:** 2026-08-03 · **Итерация 4 UI/данных** · **Статус:** согласован (правка: архив — полоска в правой панели)

## 1. Цель

Шесть связанных улучшений:
1. **«Когда-нибудь» под календарём:** колонка переезжает из отдельной полосы справа в нижнюю секцию правой панели (календарь сверху, «Когда-нибудь» под ним). Одна кнопка сворачивает/разворачивает всю панель целиком — в «Неделе» и в «Дне».
2. **Перенос текста везде:** строка задачи в обычном режиме (день, неделя списком, «Когда-нибудь») — авто-растущий textarea с переносом по словам, чтобы задачу было видно полностью.
3. **Заметки:** Enter — применить (сохранить и закрыть), Shift+Enter — новая строка.
4. **Сортировку по времени убрать:** порядок задач — только ручной (sortOrder); время показывается и ставится, но не сортирует.
5. **Период «Произвольный»:** в фильтре «Период» поиска появляется пользовательский диапазон «с … по …».
6. **Архив:** невыполненные задачи с прошедшей датой при запуске уходят в архив (вместо переноса на сегодня). Доступ — маленькая полоска внизу правой панели; по клику разворачивается на всю панель: выбор, что вернуть и на какую дату.

## 2. Хранение архива (флаг, миграция V6)

**Миграция `V6__archive.sql`:**
```sql
-- «Архив»: задача скрыта из видов, ждёт возврата (archived = 1).
ALTER TABLE tasks ADD COLUMN archived INTEGER NOT NULL DEFAULT 0;
```

**Модель:** `Task.archived: bool` (`#[serde(default)]`). Задача не может быть одновременно archived и someday: переносы снимают оба флага.

**Команды:**
- `get_tasks`: `WHERE date BETWEEN ?1 AND ?2 AND someday = 0 AND archived = 0`.
- `get_someday_tasks`: `WHERE someday = 1 AND archived = 0`.
- Новая `archive_overdue(today_epoch_day: i64) -> i64`: `UPDATE tasks SET archived = 1, updated_at = ? WHERE is_done = 0 AND date < ?1 AND someday = 0 AND archived = 0` (someday-задачи не трогаем; возвращает число изменённых строк).
- Новая `get_archived_tasks() -> Vec<Task>`: `WHERE archived = 1 ORDER BY date DESC, updated_at DESC`.
- Новая `restore_archived(id, date)`: `UPDATE tasks SET archived = 0, date = ?2, someday = 0, updated_at = ?3 WHERE id = ?1` (задача встаёт на выбранную пользователем дату).
- `rollover_overdue` — **удаляется** (заменён `archive_overdue`).
- `move_task` / `set_someday`: дополнительно снимают `archived = 0` (взаимоисключение).
- `upsert_task`: колонка `archived` в INSERT/ON CONFLICT.
- `export_to`/`import_from`: поле `"archived"` (импорт опционально, `unwrap_or(false)`), version остаётся 1.

**Тесты Rust:** V6 применяется (колонка есть, default 0); `archived` в serde round-trip (default false).

## 3. Правая панель «Календарь + Когда-нибудь» (+ архив)

Один блок справа на всю высоту, общий для «Недели» (оба режима: сетка и список) и «Дня»:

```
┌─────────────────────────┐
│  Мини-календарь         │  ← visibility.miniCalendar
│                         │
│ ─────────────────────── │
│  Когда-нибудь (N)       │  ← visibility.someday
│  [задачи…]              │
│  + когда-нибудь         │
│ ─────────────────────── │
│  ⚿ Архив · N           │  ← полоска-кнопка (всегда видна)
└─────────────────────────┘
```

- **WeekView:** правая панель — существующий `RightCalendar` (ширина calWidth, resize-handle), внутри которого сверху `MiniCalendar`, снизу секция «Когда-нибудь» и полоска «Архив». Кнопка тулбара «Скрыть календарь» теперь сворачивает **всю панель** (переименовать title в «Скрыть панель»).
- **DayView:** правая панель — та же структура (ширина 280). Добавляется кнопка-тогл «Календарь» (иконка) в заголовке дня — локальное состояние `showPanel` (default true), потому что тулбара в «Дне» нет.
- **SomedayColumn** превращается в секцию внутри панели: убрать `width: 280`, `borderLeft`, `flexShrink`; заголовок/список/поле «+»/droppable-зона `sd:someday` остаются. Отдельный рендер SomedayColumn справа от сетки/дня убирается.
- Условия отображения панели: как сейчас для календаря (WeekView: `showCal && !narrow && !calNarrow`; DayView: `visibility.miniCalendar && !calNarrow && showPanel`), только блок целиком. `visibility.someday` прячет только секцию внутри панели.
- Drag задачи на «Когда-нибудь» работает как раньше (зона `sd:someday` та же).

### Разворот архива

- **Полоска «Архив · N»** (N = число архивных задач) внизу панели; при N = 0 полоска скрыта. Клик → режим `archiveOpen`: панель целиком показывает список архива (календарь и «Когда-нибудь» временно скрыты). Состояние `archiveOpen` — локальное в компоненте панели (сбрасывается при скрытии панели кнопкой).
- **ArchivePanel** (новый, `src/components/ArchivePanel.tsx`):
  - заголовок «Архив» + кнопка «‹ свернуть» (возврат к календарю);
  - список архивных задач: чекбокс (отметить выполненной — upsert сохраняет archived), заголовок, кнопка **«Вернуть…»**;
  - «Вернуть…» открывает `DatePickerModal` (переиспользуем существующий: крупный MiniCalendar + Escape) — пользователь сам выбирает дату; выбор даты → `api.restoreArchived(id, epochDay)` → задача встаёт на эту дату и исчезает из архива.
- Поиск архивные задачи **не показывает** (их нет в пуле `store.tasks`) — архив открывается только из панели.

## 4. Перенос текста везде (TaskCard)

- В `TaskCard` обычный (не-компактный) режим: `<input>` с многоточием заменяется на тот же авто-растущий `<textarea>`, что и в компактной сетке (перенос по словам, авто-высота, максимум ~4 строки → скролл). Дублирование веток убрать: один textarea, `compact` влияет только на раскладку (колонка с временем vs ряд, отступы) и скрытие TimePicker.
- Клавиши (уже реализованы в onKeyDown): **Enter** без Shift — сохранить + создать следующую строку; **Shift+Enter** — перенос строки; Escape — отмена; Backspace на пустой текст у пустой задачи — удаление; blur — сохранение.
- Месяц (clamp 2 строки) и поиск (ellipsis) — превью, не трогаем.

## 5. Заметки: Enter — применить

В панели заметки (`TaskCard`, `notes-panel` textarea):
- **Enter** без Shift: `preventDefault` → `saveNotes()` + закрыть панель (`setNotesOpen(false)`) — «применить»;
- **Shift+Enter**: перенос строки (стандартное поведение);
- **Escape**: сохранить и закрыть (как сейчас);
- **blur**: сохранить (как сейчас).

## 6. Сортировка по времени — убрать

- `commands.rs` `get_tasks`: `ORDER BY sort_order ASC` (убрать `time_minutes IS NULL, time_minutes ASC`).
- `api-browser-fallback.ts` `sortTasks`: только `a.sortOrder - b.sortOrder`.
- `DayView` и `WeekViewVertical`: клиентская сортировка только по `sortOrder`.
- `SearchResults`/`SearchBar`: удалить ключи `time`/`timeDesc` из `SortKey` и опций «Сортировка»; в dateAsc/dateDesc/category вторичный ключ — `sortOrder` вместо времени.
- `TimePicker` остаётся: время ставится и показывается, но не сортирует.

## 7. Период «Произвольный» в поиске

- `PeriodFilter` += `"custom"`.
- `App`: новые состояния `searchPeriodFrom`/`searchPeriodTo` (`number | null`, epoch-day) + сеттеры; сброс при закрытии поиска и «Сбросить фильтры».
- `SearchBar`: в опциях «Период» новый пункт **«Произвольный…»**; при выборе под рядом фильтров появляется строка `с [date] по [date]` (два `<input type="date">`), изменения применяются сразу.
- `SearchResults`: при `period === "custom"` — `from != null && d >= from && to != null && d <= to`; незаполненный край диапазона не ограничивает (пусто = безгранично).

## 8. Фронт архива

- `api.ts`: `Task.archived`; `getArchivedTasks`, `archiveOverdue(today)`, `restoreArchived(id, date)`; `rolloverOverdue` удалить.
- `api-browser-fallback.ts`: фильтры `!archived` в `getTasks`/`getSomedayTasks`; `archiveOverdue` (переносит просроченные в архив, возвращает count); `restoreArchived`; `getArchivedTasks`.
- `store.ts`: `archivedTasks: Task[]` + `setArchivedTasks` (не персистится); настройка `rolloverEnabled` → `archiveEnabled`; `visibility.rolloverBanner` → `archiveBanner`.
- `App.tsx`:
  - `reload`: `Promise.all([getTasks, getSomedayTasks, getArchivedTasks])` → `setTasks([...regular, ...someday])`, `setArchivedTasks(archived)` (архивные не попадают в обычный пул — иначе засорят прошедшие дни);
  - эффект при старте (объявлен до `reload`): если `archiveEnabled` — `const n = await api.archiveOverdue(today); setArchiveCount(n)`;
  - баннер «Архивировано просроченных задач: N» (вместо «Перенесено невыполненных на сегодня»), скрывается настройкой `archiveBanner`.
- `SettingsPanel`: подпись «Авто-перенос невыполненных на сегодня» → «Авто-архив просроченных».
