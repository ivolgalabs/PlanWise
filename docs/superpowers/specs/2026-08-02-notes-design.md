# Заметки к задаче (notes) — дизайн

**Дата:** 2026-08-02 · **Фича 1 из Фазы 2** · **Статус:** согласован

## 1. Цель

У каждой задачи появляется раскрывающаяся панель с многострочным текстом заметки.
Одна заметка на задачу, plain text (без markdown). Кнопка-иконка в строке задачи,
подсвеченная, если заметка непустая.

## 2. Хранение (Rust + SQLite)

### Миграция `src-tauri/migrations/V4__task_notes.sql`

```sql
-- Заметка к задаче. '' = нет заметки.
ALTER TABLE tasks ADD COLUMN notes TEXT NOT NULL DEFAULT '';
```

### Модель `models.rs`

- В `Task` добавить `pub notes: String` с `#[serde(default)]` — старые JSON-объекты
  (браузерный фоллбек, старые бэкапы) без поля `notes` не ломают десериализацию.

### Команды `commands.rs`

- `get_tasks`: добавить `notes` последней колонкой в SELECT и в конструктор `Task`
  (порядок: `..., time_minutes, notes`).
- `upsert_task`: `notes` в INSERT (параметр ?11) и в `ON CONFLICT ... DO UPDATE SET
  notes=excluded.notes`.
- `export_to`: в JSON задачи — поле `"notes"`.
- `import_from`: читать `"notes"` опционально (`unwrap_or("")`).
  **Версия бэкапа остаётся `1`** — старые файлы без поля импортируются как раньше,
  новые — с заметками. Строгая проверка `version != 1` не меняется.

## 3. UI (TaskCard + Icon)

- **Icon.tsx**: новая иконка `note` (лист бумаги с линиями, стиль набора).
- **TaskCard**: кнопка-иконка рядом с `TimePicker`, всегда видна (НЕ зависит от
  `visibility.taskActions`). Активная подсветка (акцент), если `task.notes` непустая.
  title-подсказка: «Заметка».
- Клик → разворот панели под строкой (внутри `.task-block`, как `SubtaskList`):
  textarea с авто-высотой (min-height ~2 строки, растёт по контенту),
  placeholder «Заметка…».
- Локальный стейт текста; синхронизация извне при изменении `task.notes`
  (паттерн `title` в TaskCard: `useEffect`, если панель не в фокусе).
- **Сохранение:** по `blur` → `api.upsertTask({ ...task, notes })`. `Enter` — обычный
  перенос строки (textarea). `Escape` — свернуть панель с сохранением.
- Подзадачи и заметки — две независимые панели, не конфликтуют.

### Настройка видимости

- `store.ts`: `VisibilityState` + `DEFAULT_VISIBILITY` — флаг `notes: true`.
- `SettingsPanel.tsx`: строка `["notes", "Заметки"]` в секции «Интерфейс».
- При выключенном флаге скрываются и кнопка, и панель (паттерн `subtasks`).

## 4. Браузерный фоллбек (тесты UI без Rust)

- `api.ts`: поле `notes: string` в интерфейсе `Task`; в `upsertTask` при сборке
  объекта — `notes: task.notes ?? ""`.
- `api-browser-fallback.ts`: при upsert нормализовать `notes: task.notes ?? ""`
  (старые записи localStorage без поля).

## 5. Вне скоупа

- Несколько заметок, markdown/форматирование, поиск по заметкам,
  экспорт вложений (отдельная фича).

## 6. Проверка

- `cargo check` в `src-tauri` (общий target/ — сборку не дублировать).
- `npm run build` (tsc + vite).
- Ручной сценарий в Tauri: создать заметку → blur-сохранение → перезапуск
  (заметка на месте) → сворачивание/разворачивание → настройка «Заметки» off.
- Экспорт → импорт: заметки сохраняются; старый бэкап (version 1 без notes)
  импортируется без ошибок.
- Браузерный фоллбек: заметка создаётся/сохраняется/переживает reload.
