# UI-фиксы 2: сетка (время внизу), месяц (перенос), сортировка, категории, кнопки — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вторая итерация UI-правок: (1) в сетке недели текст задач получает всю ширину колонки, время переносится под текст; (2) в месяце текст задач переносится (не обрезается и не исчезает); (3) в сортировке поиска появляются «Я-А» и «По времени ↓»; (4) браузерный фоллбек получает дефолтные категории (Работа/Личное/Спорт); (5) кнопки-«пилюли» (radius-full) приводятся к стилистике интерфейса (radius-md).

**Architecture:** Чисто фронтовые правки. TaskCard в компактном режиме (сетка недели) перестраивается: инпут и TimePicker — в flex-колонке (текст на всю ширину, время мелкой строкой под ним; вторая строка только при наличии времени). MonthTaskPreview меняет nowrap+ellipsis на перенос с лимитом 2 строки. SortKey расширяется (`alphaDesc`, `timeDesc`) в SearchResults + опции в SearchBar. Фоллбек сидит дефолтные цвет-сеты при первом обращении (если ключ не существует). Четыре места `radius-full` → `radius-md`.

**Tech Stack:** React 19 + TypeScript, Vite, zustand.

- Produces: при первом обращении к `getColorSets` (ключ `fb:sets` отсутствует в localStorage) записываются дефолтные сеты — те же, что сид V1 в SQLite (ARGB-int: cs-none 4293979362, cs-work 4291405948, cs-personal 4286494916, cs-sport 4293437564). - [ ] **Step 1: Сид дефолтных сетов**

В `src/api-browser-fallback.ts` после константы `K` добавить:

```ts
// Дефолтные категории — как сид V1 в SQLite (ARGB-int = 0xFFRRGGBB).
// Пишутся при первом обращении, если ключа ещё нет в localStorage.
const DEFAULT_SETS: ColorSet[] = [
  { id: "cs-none", name: "Без категории", color: 4293979362, sortOrder: 0 },
  { id: "cs-work", name: "Работа", color: 4291405948, sortOrder: 1 },
  { id: "cs-personal", name: "Личное", color: 4286494916, sortOrder: 2 },
  { id: "cs-sport", name: "Спорт", color: 4293437564, sortOrder: 3 },
];
```

Заменить `getColorSets`:

```ts
  async getColorSets(): Promise<ColorSet[]> {
    // Первый запуск (или после очистки storage): создаём дефолтные категории.
    if (localStorage.getItem(K.sets) === null) {
      save(K.sets, DEFAULT_SETS);
    }
    return load<ColorSet>(K.sets).sort((a, b) => a.sortOrder - b.sortOrder);
  },
```
