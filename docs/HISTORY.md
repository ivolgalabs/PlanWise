# PlanWise — release history

Moved out of `PROJECT.md` (11.10.2026) to keep the anchor small; newest first.

Current version: 0.2.3 (0.2.3 — audit 11.10 fixes (`docs/reports/2026-10-11-audit-plan.md`): the Android digest no longer arrives twice (an OS-alarm fire is recorded as `sent_day` when the target moves past the hour — `retarget_digest`); turning off both notification toggles cancels the armed alarms on Android; the desktop digest is deduped across relaunches (persisted `sent_day`); the digest text starts with the date (a stale repeating alarm is recognisable); marking a task done from the widget cancels its reminders (Rust writes `files/notify-tasks.json`, Kotlin cancels); auto-import is skipped while an export is pending (lost-edit race); the priority sort ranks a hard untimed task above easy timed ones; import stages attachment files as tmp + rename after commit (a failed import no longer deletes live files); `notify_minutes` clamped to 7 days; restore of a past-day task skips the overlap check; scheduler mutexes survive poisoning. Optimisations: auto-sync runs in Rust (`sync_export`/`sync_import` — no multi-MB JSON over IPC), non-default locales are lazy chunks (main JS 550 → 434 KB). 0.2.2 — Android digest CATCH-UP: the OS alarm is armed only for a day that ALREADY has tasks before its hour, and after the hour the target flips to tomorrow, so a day planned in the morning got NO digest at all («не вылезают»). Now every sync tick inside the +6 h window after the configured hour shows «План на сегодня» once for a day that had neither an armed alarm nor a show — `digest_catchup_due` (pure, unit-tested) + a persisted marker `notify-digest.json` (armed_day/sent_day; a separate file, because the UI rewrites prefs wholesale). Task row on touch: a tap must now be a CLEAN tap (movement >10 px = scroll, ignored — scrolling used to open inline text editing), and a clean tap on the row OPENS THE CARD (the ✎ target is only 20-24 px); desktop unchanged (click on empty row space = edit text). 0.2.1 — tasks «в течение дня» (time_minutes NULL) now REMIND: one morning ping on the task's day at the digest hour, but ONLY when the digest is OFF — with the digest on, it already announces them at the same minute (no double ping); the reminder query no longer filters `time_minutes IS NOT NULL` (`ReminderRow.2` → Option, `morning_of`); card UI: `Перенести/Дублировать/Удалить` moved to their own row — on narrow screens they no longer push «Сохранить» past the card edge; hint «напомним утром» for time-less tasks (`form.allDayHint`, i18n ×9; 3 new unit tests). 0.2.0 — 9-language localization (ru/en/es/de/fr/pt/zh/ja/ko) incl. localized notifications via the `set_app_lang` bridge. 0.1.18 — task duplication («Дублировать» → Rust `duplicate_task`, full copy with subtasks, reminders re-arm for the copy, generic-Reminder vs travel/prepare same-minute dedup). 0.1.17 — the Android digest became a REPEATING Interval OS alarm (survives process death and reboot; BOOT receiver restores it; failed `show()` aborts the store write); since 0.2.2 the catch-up makes the digest independent of that alarm chain. 0.1.15/0.1.16 — BACK minimizes the app (warm relaunch); digest re-arms on day-content fingerprint change. Releases in `Ready-made versions of applications/PlanWise`).
